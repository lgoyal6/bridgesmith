    TRY A FAILURE
    Different gates, different answers.
    • A wrong total type fails schema validation.
    • A wrong item count can pass the schema and fail a declared semantic invariant.
    • A retired or revoked key blocks mounting before the catalog is read.
    • Fresh certification after retirement issues a certificate under the active key.
    BOUNDARIES
    What a passing run establishes
    • The root and keys are ephemeral for each run. This is a trust-lifecycle demonstration, not a production registry or independent authority.
    • Expiry uses the server clock. The expiry scenario advances its evaluation clock; trusted historical time remains open.
    • Only the named invariants are checked. Broader nested-list semantic mutation misses remain open.
    • Synthetic results do not establish real provider recovery, customer use or general connector correctness.
